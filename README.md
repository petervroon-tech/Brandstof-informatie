# Brandstof-informatie

Echte landelijke pompprijzen en tankstations in de buurt. Alle gegevens komen uit een echte bron; er worden geen prijzen berekend of verzonnen.

| Onderdeel | Bron |
|---|---|
| Landelijk gemiddelde Euro 95, Diesel, LPG + prijsontwikkeling | CBS StatLine 80416NED (open data, dagprijzen) |
| Tankstations (naam, merk, adres, openingstijden, brandstoffen) | OpenStreetMap via Overpass API |
| Postcode/plaats zoeken, adressen aanvullen | PDOK Locatieserver |

**Geen prijs per pomp:** daarvoor bestaat geen open, betrouwbare bron. Eerdere versies (t/m 2.4.x) toonden berekende prijzen per station; die waren niet gemeten en zijn verwijderd (v3.0.0).

Live: https://petervroon-tech.github.io/Brandstof-informatie/
